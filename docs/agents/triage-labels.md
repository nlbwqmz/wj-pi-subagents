# Triage 标签

各技能使用五个 canonical triage role。本文件将这些 role 映射到本仓库实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估此 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整说明，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个 role（例如应用 AFK-ready triage 标签）时，使用右侧对应的标签字符串。
