# Triage 标签

工程技能使用五类标准 triage 角色。下表把这些角色映射到本仓库 Issue 跟踪器实际使用的标签字符串。

| `mattpocock/skills` 中的标签 | 本仓库使用的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估该 Issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交由无人值守（AFK）代理处理 |
| `ready-for-human` | `ready-for-human` | 需要由人工实现 |
| `wontfix` | `wontfix` | 不会处理该 Issue |

当技能提到某个角色时，例如“应用可由无人值守代理处理的 triage 标签”，应使用上表中对应的本仓库标签字符串。

如果本仓库以后更换标签命名约定，可以直接修改表格中“本仓库使用的标签”一列。
