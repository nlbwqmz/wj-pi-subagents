# 真实子控制器直连监督通道并逐跳访问根权威

Status: accepted

受管 bridge 只在父侧高层协议与真实子 Pi 扩展之间认证并透明转发有界监督字节，不创建伪 child 端点，也不能通过任务 RPC 复制 assistant 回复；真正的子控制器持有监督会话、发布完整子树、上行直接回复并响应关闭。身份、全树配额、模板修订、终止屏障和资源确认由唯一根代理树权威线性化，普通子控制器只能沿已认证的直接父子监督关系逐跳请求裁决，不能共享进程内控制器注册表或直接访问祖先控制器。

父端 close 已经代表根权威建立了固定子树屏障，child 随后的后代优先清理只使用本地直接子监督关系，不能再通过已经进入 closing 的上游通道重复请求同一屏障。直接父确认目标平台进程树边界已经回收时，根权威按屏障固定的后代优先顺序确认该边界覆盖的残留后代；若目标是运行故障的中间父，则后代可以据此释放，但故障父自身继续保持 `failed` 和名额，直到直接父显式终止它。
