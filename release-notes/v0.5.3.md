# v0.5.3

## 新增

- 新增 `WJ_PI_SUBAGENTS_BRIDGE_RUNTIME` 环境变量：可在启动 Pi 前显式指定子代理桥接进程使用的 JS 运行时（运行时可执行文件路径），适合需要固定运行时版本或自动解析不适用的情况。

## 优化

- 用户级模板目录与用户级运行时配置现在跟随 Pi 的用户级 agent 目录设置：识别 `PI_CODING_AGENT_DIR` 环境变量（支持 `~` 展开），未设置或为空串时仍回退到 `<用户主目录>/.pi/agent`。在自定义 Pi agent 目录的环境中，用户级模板和配置也能被正确加载，与 Pi 自身行为保持一致。
- 代理间消息正文上限统一提升到 64 KiB：父代理向子代理下发的指令正文上限由 16 KiB 提升到 64 KiB，子代理回传的回复正文上限由 32 KiB 提升到 64 KiB，长指令、长报告有更大的传输空间。

## 修复

- 修复了 Pi 以单文件编译产物运行时子代理桥接进程无法启动的问题：当 Pi 自身的可执行文件不是 `node`/`nodejs`/`bun` 时，现在会从 `PATH` 中依次解析 `node`、`bun` 来运行桥接脚本。
- 修复了桥接运行时缺失时只能等待启动超时的问题：无法解析到可用运行时时，`spawn_agent` 会立即以 `spawn_failed` 失败并给出明确原因，而不是等待启动超时。
