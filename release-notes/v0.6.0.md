# v0.6.0

## 新增

- 模板新增 `excludeTools` 字段：可以从子代理移除指定业务工具，条目支持 `*` 通配（需要 pi 1.1.0 及以上），排除在工具注册阶段生效，被排除的工具即使经 codemode 这类间接路径也不可达；`tools` 与 `excludeTools` 同时覆盖某个工具时排除优先；空数组与不写等价。排除项不得命中子代理的协议工具——协议工具名，以及 `*`、`*report*` 这类可能匹配协议工具的模式，都会让模板在加载期被判为无效。模板清单会一并显示声明的排除项。

## 优化

- 模板工具声明与排除声明在加载期收窄为白名单写法：`+name` / `-name` 修饰符不再被接受，含修饰符的模板在加载期即被判为无效，诊断直接指向模板与具体字段；此前这类写法要么让子进程失败却看不出原因，要么被静默忽略。
- 子代理任务交接提示文本统一为英文，跨语言场景下表述一致。

## 修复

- 修复了含 `*` 通配的模板无法派发子代理的问题：这类模板此前始终无法启动，现在可以正常使用（`*` 需要 pi 1.1.0 及以上；旧版本会把它当作字面工具名，子代理将没有任何业务工具）。
- 修复了拼错工具名导致子代理启动被拒的问题：工具名写错不再阻止启动，只会静默少一个工具，与 pi 自身行为一致；子代理实际拿到的活动工具集仍会上报并进入能力清单。
