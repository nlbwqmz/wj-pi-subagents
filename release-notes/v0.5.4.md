# v0.5.4

## 新增

- 子代理模板的 `extensions` 字段新增支持 `builtin:<name>` 内置扩展来源：可直接引用 Pi 内置扩展（例如 `builtin:mcp`）为子代理启用内置能力，无需借助本地文件、npm 包或远程地址；该用法需要 pi 0.99.0 或更高版本。

## 优化

- 完善中英文文档中的扩展配置说明：明确 `extensions` 支持的来源类型（本地路径、`npm:`、`git:`、URL、`builtin:<name>`），说明声明 `extensions` 时未列出的内置扩展会被一并屏蔽，并补充仅加载内置 MCP 扩展的示例，方便用户按需配置。
