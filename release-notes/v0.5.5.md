# v0.5.5

## 新增

- 子代理活动面板新增内置扩展工具的调用详情：codemode 条目可展开查看它执行的脚本内容，tool_search 条目显示查询词与加载到的工具，MCP 工具与 MCP 资源工具显示所属服务器、工具名或资源地址。此前这些调用在面板上只能看到状态图标与工具名。
- codemode 条目在折叠态直接显示脚本行数与脚本内嵌套调用数，不展开也能判断这次调用的规模；展开与折叠沿用面板既有交互，无需学习新的操作方式。
- MCP 工具显示工具声明的风险注解（只读、破坏性、幂等、开放世界），仅显示实际声明的项，便于评估这次调用的性质。

## 优化

- tool_search 条目在折叠态列出加载到的工具名（最多 20 个），工具更多时同时给出实际总数（如 `20/35 tools`），便于判断它发现了什么。
- 单次 codemode 调用的嵌套记录超过 256 条时，面板以一行“其余 N 条省略”聚合显示，避免活动面板被海量条目淹没。

## 修复

- 修复了脚本内的嵌套工具调用在面板上与子代理直接调用无法区分、容易误判调用链的问题：嵌套条目现在带 `codemode->` 前缀，多级调用链完整呈现（超过三层时中间层以 `…` 省略）。
- 修复了子代理执行超长命令时活动条目因内容过长被拒、面板上看不到该次调用的问题：超长命令现在会按行截断并标注 `…（已截断，原文共 N 行）`，codemode 脚本同样遵循这一截断规则。
