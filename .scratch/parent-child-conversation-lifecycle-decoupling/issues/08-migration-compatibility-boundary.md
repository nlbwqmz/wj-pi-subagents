# 旧内部协议与运行时迁移边界

Status: resolved
Type: grilling
Blocked by: 03, 04, 06, 07

## Question

本次重构是否需要兼容现有监督协议版本、`ChildReplyEnvelope` v5、热重载交接、已运行中的旧父子进程或未升级的子代理？用户配置和模板明确不在范围，但内部消息字段和 final 机制可能发生结构性变化；需要决定协议是否整体升级、是否保留过渡解析、旧实例如何结束，以及哪些不兼容可以明确拒绝而不扩大重构范围。

## Answer

本票据将本次重构定义为一次 **clean break**，不建立旧版本兼容窗口、版本协商或跨版本迁移。

### 协议边界

新实现发布新的监督 wire 与消息信封契约，只解析新规格定义的字段和生命周期投影。旧 `wj-pi-subagents/13`、`ChildReplyEnvelope` v5、旧 final/任务租约、ACK/发送窗口及其关联解析器、转换器和降级分支全部从新实现中移除；收到旧版本或旧字段时，在 bootstrap、握手、manifest 或协议入口立即拒绝，返回稳定的 `protocol_mismatch`/启动失败。协议故障不伪装成普通消息发送失败，也不自动重试。

### 运行实例与 reload

旧父子进程只能由旧 runtime 持有并运行；新 runtime 不附着、不接管、不转换旧进程。旧父子双方在没有新实例接管时可以继续自己的旧会话，但这不构成本 effort 支持的新旧共存契约；clean break 部署要求旧 runtime 先结束旧树。

reload lease 只允许同一新规格内的交接：协议版本、消息契约、七个生命周期状态及其投影、transfer 对象结构和方法契约必须全部匹配。新实例无法认领旧 lease 或不兼容 transfer 时，旧 runtime 保留所有权并在有界期限内执行正常 shutdown/资源清理；清理未确认时保留 `terminating`/清理不完整事实，不把节点伪装成已被新实例接管。新实例不得抢占根权威或复用旧对象。

### 混合版本故障

新父端连接旧子端、旧父端连接新子端，或任何旧/新 bootstrap、握手、manifest 不匹配，都立即报告 `protocol_mismatch`。监督器提交真实协议运行故障，生命周期权威进入 `failed`，随后按正常终止流程确认资源释放；不等待应用超时、不尝试旧格式、不降级为 `idle`。

### 在途状态

跨版本边界不迁移应用消息、`final_report` 正文、旧任务/回合状态、旧 ACK/窗口状态、压缩屏障或父端上下文。尚未被 Pi 接纳的旧调用丢弃并返回发送失败；已经被旧 Pi 接纳的内容仍属于旧会话，不由新 runtime 重放、改写或重新排序。新 runtime 只从兼容的新规格状态开始。

### 发布范围

本次是破坏性发布，不支持新旧 runtime 滚动升级、跨版本 lease、旧会话迁移工具或双版本并存。实现会话只需交付新协议的全量替换、严格版本拒绝和同规格 reload 测试；用户配置、模板及外部数据迁移仍在本 effort 之外。
