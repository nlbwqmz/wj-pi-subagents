## Answer

`README.md` 与 `README.zh-CN.md` 的代理模板章节新增「Tool declaration and exclusion」/「工具声明与排除」小节，并更新模板字段表与省略/空数组对照表：`工具声明` 只支持白名单写法（纯工具名与 `*` 通配，`*` 可在任意位置、可出现多次）；`+name` / `-name` 修饰符不受支持，含修饰符的模板在加载期判为无效；`*` 需要 pi ≥ 1.1.0，旧版本把 `*` 当字面工具名、得到零业务工具的子代理；pi 1.1.0 起白名单不再排他（未列名的 MCP 工具仍注册、可经 codemode 一类间接路径调用），`excludeTools` 用于表达排除；排除项遵循与 `tools` 相同的名字形状规则并支持 `*` 通配，在工具注册阶段生效，与 `工具声明` 同时出现时排除优先；不写 `工具声明` 不改动宿主默认工具集，写空数组不启用常规业务工具（pi 1.1.0 起未列名 MCP 工具仍注册，需用 `excludeTools` 移除）；扩展不校验实际活动工具集是否等于声明，拼错的工具名静默少一个工具。
