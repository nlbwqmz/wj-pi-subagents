# 04 — 模板编写文档：工具声明与排除

**What to build:** 模板编写文档说明 `工具声明` 的语法边界与排除字段用法，使模板作者只读文档就能预测子代理的能力边界，不必靠试错。

**Blocked by:** 01、02、03

**Status:** ready-for-agent

- [ ] 写明 `工具声明` 只支持白名单写法：纯工具名与 `*` 通配（`*` 可在任意位置、可出现多次）
- [ ] 写明 `+name` / `-name` 不受支持，含修饰符的模板会在加载期被判为无效
- [ ] 写明 `*` 需要 pi ≥ 1.1.0；旧版本会把 `*` 当字面工具名，得到零业务工具的子代理
- [ ] 写明排除字段的用法，以及它与 `工具声明` 同时出现时的优先级（排除优先）
- [ ] 写明不写 `工具声明` 时不改动宿主默认工具集；写空数组表示不要任何业务工具
- [ ] 写明扩展不校验实际活动工具集是否等于声明——拼错的工具名会静默少一个工具，不会被拦下
- [ ] 中英文档同步更新
