# 01 — 在加载期拒绝工具声明的修饰符形态

**What to build:** 模板作者在 `工具声明` 里写 `+name` / `-name`（无论单独出现，还是与普通工具名混用）时，模板被判为无效，并得到一条指向该模板与 `tools` 字段的诊断；纯工具名列表与含 `*` 通配的列表照常有效。作者因此不必等到子进程启动失败或静默少工具才发现写法不被支持。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 含 `+name`、`-name`、或修饰符与普通名混用的模板被判为无效，诊断定位到该模板与 `tools` 字段
- [ ] 纯工具名列表、含 `*` 的列表（`*` 出现在首/中/尾、出现多次）仍判为有效
- [ ] 既有 `tools` 相关诊断行为不变：非数组、空串、重复项、保留系统工具名
- [ ] 诊断文案可读，说明修饰符形态不受支持（基准集来自宿主默认工具配置，扩展无法保证声明与实际一致）
- [ ] 既有纯名字模板用例全部保持通过
