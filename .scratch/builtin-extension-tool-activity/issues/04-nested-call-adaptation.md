# 04 — 嵌套调用适配

**What to build:** codemode 脚本内的嵌套调用不再伪装成独立直接调用——产生端采集 Pi 事件上的 `parentToolCallId`；面板把嵌套调用显示为独立条目并在工具名前加 `codemode->` 前缀（多级链完整拼接为 `codemode->A->B`，超过 3 层时中间省略为 `codemode->…->B`）；嵌套条目自身的摘要与折叠能力保持（该有摘要的照常显示、该可折叠的照常可折叠）；单次调用超过 256 条嵌套记录时在面板上聚合显示"其余 N 条省略"。

**Blocked by:** 03 — tool_search 与 MCP 适配

**Status:** ready-for-agent

- [ ] 产生端采集 `parentToolCallId`（有界校验）并随活动条目携带；无父引用的条目行为不变
- [ ] 面板对嵌套条目渲染 `codemode->` 前缀；多级链按完整调用链拼接，超 3 层中间省略
- [ ] 嵌套条目自身的摘要渲染不回归（如嵌套的 `read` 显示 path、嵌套的 MCP 工具显示 server/tool）
- [ ] 嵌套条目的折叠/展开能力与普通条目一致（不因前缀改变交互）
- [ ] 单次调用超过 256 条嵌套记录时聚合显示"其余 N 条省略"
- [ ] wire 闭集校验覆盖父引用字段：未知键、非法组合拒绝
- [ ] 端到端可演示：codemode 脚本调用多个工具后，面板出现带前缀的嵌套条目（含一次多级链与一次超量聚合）
- [ ] 活动事实语义不变：嵌套条目与普通条目同等待遇（活动窗口裁剪、滚动、选中），不改变生命周期
