# 31 - 交付常驻 `Agents` 状态 widget

**What to build:** 让 Pi TUI 持续显示当前会话直接子代理的安全、稳定和可扫描状态，而不提供越权控制或把状态写进模型上下文。

**Blocked by:** 28 - 交付递归创建、能力衰减与只读树查询；30 - 闭合故障、防孤儿、根关闭与 reload 交接

**Status:** ready-for-agent

- [ ] 根会话只显示根直接子代理，普通父会话只显示自身直接子代理，不显示祖先、兄弟或越级后代，也不提供发送、中断、终止或 reload 按钮。
- [ ] 行按稳定顺序显示 `template_id`、名称、生命周期、可选安全活动摘要、创建后的生命周期时间、非零 pending 和稳定故障码，并在窄宽度下安全截断。
- [ ] widget 只消费控制器确认的安全快照；状态、pending、计时、终止记录和级联修订按单一 `tree_revision` 原子更新，不显示 prompt、回复、工具参数/结果、路径、环境、句柄或推理。
- [ ] `failed` 与 `termination_incomplete` 按可见作用域每批聚合一次脱敏 UI 通知，正常变化不通知、不追加会话消息。（REQ-044、REQ-046..047；AC-024、AC-026）
