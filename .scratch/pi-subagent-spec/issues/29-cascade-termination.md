# 29 - 交付同步级联终止与部分资源回收

**What to build:** 让父会话永久终止一个直接子代理及其当时已登记的整棵子树，并在资源无法完全确认时保留可重试的终止状态。

**Blocked by:** 27 - 交付竞态安全的等待与协作式中断；28 - 交付递归创建、能力衰减与只读树查询

**Status:** ready-for-agent

- [ ] `terminate_agent` 不接受单节点或 `cascade` 选项；在一个树线性化点固定目标、原子建立所有终止屏障，拒绝屏障后的普通消息、创建和控制。
- [ ] 清理按后代屏障、活动 abort、未写命令取消、EOF、内部期限、平台强制整树回收和最终资源观察的顺序执行；信号成功不等于 `terminated`。
- [ ] 后代及本节点全部确认后同步成功，重复或并发调用合并到同一流程并准确返回新增终止数量；部分确认时已回收节点先进入 `terminated` 释放名额，未确认节点保持 `terminating` 并返回 `termination_incomplete`。
- [ ] 测试覆盖迟到事件、屏障竞态、活动任务、孙进程残留、兄弟部分失败、幂等重试和无孤儿。（REQ-029、REQ-041..042；AC-016、AC-022）
