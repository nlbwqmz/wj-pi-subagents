# 18 - 冻结根工作基础、环境、信任与配置

**What to build:** 让根 Pi 会话在启动时确定整棵代理树共享的工作目录、项目资源信任、环境快照和数量配置，并让后代只能继承这份快照。

**Blocked by:** 16 - 交付可原子失活的 Pi package 与宿主兼容门禁

**Status:** ready-for-agent

- [ ] 根会话只捕获一次固定 `cwd`、project trust 和环境变量快照；后代沿用它，模板和中间父会话不能覆盖或扩张环境，也不形成 cwd 沙箱。
- [ ] `maxDepth`、`maxChildrenPerAgent`、`maxAgentsPerTree`、`waitTimeoutMs` 按根参数、可信项目、用户配置、默认值逐字段解析并固定传给整棵树。
- [ ] 显式根参数的类型、整数性和边界错误拒绝启动；配置文件不可读、坏 JSON、选中层字段非法或未知字段按规范回默认并只作 UI-only 诊断。
- [ ] 诊断说明逻辑来源、字段和采用值，但不包含绝对路径、秘密、正文、堆栈，也不创建会话消息或模型上下文；配置和外部路径行为有自动化测试。（REQ-007..010；AC-002、AC-004、AC-005、AC-026）
