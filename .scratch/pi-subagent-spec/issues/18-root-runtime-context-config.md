# 18 - 冻结根工作基础、环境、信任与配置

**What to build:** 让根 Pi 会话在启动时确定整棵代理树共享的工作目录、项目资源信任、环境快照和数量配置，并让后代只能继承这份快照。

**Blocked by:** 16 - 交付可原子失活的 Pi package 与宿主兼容门禁

**Status:** resolved

- [x] 根会话只捕获一次固定 `cwd`、project trust 和环境变量快照；后代沿用它，模板和中间父会话不能覆盖或扩张环境，也不形成 cwd 沙箱。
- [x] `maxDepth`、`maxChildrenPerAgent`、`maxAgentsPerTree`、`waitTimeoutMs` 按根参数、可信项目、用户配置、默认值逐字段解析并固定传给整棵树。
- [x] 显式根参数的类型、整数性和边界错误拒绝启动；配置文件不可读、坏 JSON、选中层字段非法或未知字段按规范回默认并只作 UI-only 诊断。
- [x] 诊断说明逻辑来源、字段和采用值，但不包含绝对路径、秘密、正文、堆栈，也不创建会话消息或模型上下文；配置和外部路径行为有自动化测试。（REQ-007..010；AC-002、AC-004、AC-005、AC-026）

## Answer

新增 `src/root-runtime-context.ts`，提供不可变的 `RootRuntimeContext` 快照和后代派生接口。根捕获并固定规范化 `cwd`、project trust、环境变量和配额配置；子代理及更深后代只能从根环境复制，并只追加控制器生成的身份、父标识、深度、`maxDepth`、根关联和协议版本元数据。`resolvePath` 仅以根 `cwd` 为相对路径基点，不检查路径是否位于工作区内，因此没有额外的 cwd 沙箱。上下文的 JSON 投影省略环境快照，避免秘密进入树状态或诊断。

配置解析按显式根参数、可信项目 `.pi/subagent.json`、用户 `~/.pi/agent/subagent.json`、内置默认值逐字段选择。已解析字段不会读取被遮蔽的低优先级层；文件缺失继续下读，文件不可读/坏 JSON/结构错误或选中字段非法直接采用该字段默认值，不回退更低层。显式根参数严格拒绝非对象、非整数和越界值。未知字段被忽略并以逻辑来源、字段和采用值组成的安全诊断记录；诊断只可通过可选的 `ui.notify(..., "warning")` 汇总一次，通知异常和无 UI 模式均静默，不触碰会话消息或模型上下文。

测试位于 `test/root-runtime-context.test.ts`，覆盖三代环境继承、trust/cwd 覆盖阻断、外部路径解析、四字段优先级与边界、未信任项目、文件/JSON/UTF-8/字段错误、懒读取、单次 UI 通知和秘密脱敏。验证：`npm run check` 通过。
