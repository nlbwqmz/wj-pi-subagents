# 确定深度、并发与资源配额

Type: grilling
Status: resolved
Blocked by: 03, 04, 05

## Question

`maxDepth` 的配置来源、默认值、硬上限和覆盖优先级是什么，并应如何限制每个父会话的直接子代理数、整棵树的节点数、同时运行数、模型成本、空闲时长与创建速率？配额耗尽时应采用拒绝、等待还是回收，以及父子层级如何获得清晰反馈？

## Answer

### 根配额配置

根会话启动时一次性解析代理树配额，生效值固定传给整棵树；模板、子代理和后代不能覆盖或提高。配置优先级从高到低为：

1. 根启动参数；
2. 已获信任项目的 `<cwd>/.pi/subagent.json`；
3. 用户级 `~/.pi/agent/subagent.json`；
4. 内置默认值。

项目配置只有在根 project trust 允许项目设置时参与。支持的数量字段如下：

| 字段 | 默认值 | 合法范围 | 代码硬上限 | 统计对象 |
| --- | ---: | ---: | ---: | --- |
| `maxDepth` | `2` | `1..8` | `8` | 子代理层级；根深度固定为 `0` |
| `maxChildrenPerAgent` | `4` | `1..16` | `16` | 每个父会话的直接子代理 |
| `maxAgentsPerTree` | `16` | `1..64` | `64` | 根会话之外尚未进入 `terminated` 的全部节点 |

显式根启动参数只要存在即参与校验；类型、整数性或范围非法时直接拒绝根会话启动。配置层未提供某个字段时，继续按低优先级层解析；但一旦被选中的用户级或项目级配置层对该字段提供了不可读、JSON 无法解析或非法/超范围值，该字段直接采用对应内置默认值，不回退到更低优先级层。根会话通过 UI-only warning 告知采用的默认值。未知字段通过同一 UI-only warning 提示后忽略。配置诊断不创建会话消息、系统提示或模型上下文条目。

### 深度与工具可见性

根会话为深度 `0`。只有当父节点当前深度小于有效 `maxDepth` 时才允许创建下一层；达到上限的节点隐藏整组七个子代理管理工具。默认情况下根可以创建深度 `1` 的 A，A 可以创建深度 `2` 的 A-1；A-1 是叶节点。服务端即使收到绕过工具可见性的创建请求，也返回不可重试的 `max_depth_reached`。

### 直接子代理与全树名额

- `maxChildrenPerAgent` 在每个父会话上独立计数，不按深度汇总。`starting`、`idle`、`working`、`interrupting`、`failed` 和 `terminating` 都占用父节点名额；只有节点及其子树完成资源回收并进入 `terminated` 后才释放。创建前必须原子预留直接子代理名额，达到上限立即返回可重试的 `max_children_reached`。
- `maxAgentsPerTree` 统计根会话之外全部尚未 `terminated` 的节点，与直接子代理上限独立。创建前必须与直接子代理名额一起原子预留；节点及其子树完成资源回收后同时释放全树名额。达到上限立即返回可重试的 `max_tree_agents_reached`。
- 终止记录可以继续出现在状态和树快照中，但不占任何名额，也不能恢复或重新接收任务；代理标识不复用。

### 不增加的资源控制

本版本不增加以下扩展层控制：

- 不设置 `maxConcurrentRuns` 或其他同时运行数上限。不同节点可以并行处理；同一节点仍遵守既有命令串行通道，已在 `working` 中收到 steering 不新增配额计数。
- 不设置按节点、父会话或整棵树计算的 token/费用预算；模型和账户限制沿用 Pi 现有机制。
- 不设置自动空闲超时。`idle` 节点保留到父会话显式终止或根会话结束；`wait_agent.timeout_ms` 只结束一次等待，不触发回收。
- 不设置创建速率、时间窗口节流或创建队列；`spawn_agent` 只受深度、直接子代理、全树名额和启动结果约束。

因此没有并发耗尽、成本耗尽、空闲回收或创建速率耗尽错误码，也不自动等待或回收资源。配额耗尽统一立即拒绝：深度错误不可重试，直接子代理和全树错误在显式终止并完成资源回收释放名额后可由调用方重试。

### 一致性要求

深度、直接子代理名额、全树名额、节点状态和树修订必须在同一控制器状态下原子更新。并发创建不能超卖任一名额；启动失败或超时必须回收残留进程并释放预留。既有节点不因根配置变化而回溯改变，根会话结束时统一终止并回收整棵临时代理树。
