# 30 - 闭合故障、防孤儿、根关闭与 reload 交接

**What to build:** 让代理树在运行故障、父节点异常、根会话切换或扩展 reload 时保持明确的所有权和清理语义，不留下孤儿进程或旧控制面。

**Blocked by:** 19 - 发布可信代理模板发现快照；29 - 交付同步级联终止与部分资源回收

**Status:** ready-for-agent

- [ ] 启动后进程退出、RPC EOF、非法事件、身份篡改或协议无法重同步时进入稳定 `failed`，不自动重启、不恢复、不复用身份；中间父故障立即为已登记后代建立防孤儿终止屏障。
- [ ] 故障父节点保留 `failed` 和名额，直到直接父显式终止并确认整个子树；部分级联结果继续遵守 `terminating`/`terminated` 和资源确认边界。
- [ ] 根退出、`new`、`resume`、`fork` 或 runtime 真正关闭时从根直接子树开始清理，内部期限超期只作 UI-only 错误，不无限阻塞或提前释放未确认名额。
- [ ] 成功根 reload 保留既有节点和树控制身份，只刷新未来模板/动态资源；新扩展实例门禁失败时按终止语义清理全部旧节点、端点、widget 和监督器。（REQ-003、REQ-017、REQ-043；AC-001、AC-008、AC-023）
