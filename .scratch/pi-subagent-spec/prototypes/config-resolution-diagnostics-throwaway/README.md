# 配额配置诊断原型（THROWAWAY）

> 这是用于回答配置优先级与诊断语义的可抛弃原型，不是扩展生产代码，不应直接打包或发布。

## 要回答的问题

高优先级的 `maxDepth` 配置无效时，是否会回退到低优先级配置，还是直接采用内置默认值；配置诊断是否能只展示给用户而不进入模型上下文？

## 运行

仓库没有现成任务运行器，直接使用已安装的 Node.js：

```powershell
node .scratch/pi-subagent-spec/prototypes/config-resolution-diagnostics-throwaway/demo.mjs
```

脚本依次展示：项目配置值超范围、项目配置 JSON 无法解析、未知字段，以及非法显式根参数。每个场景都会打印完整的解析结果、UI 警告和模型上下文条目。

## 原型结论

- 合法显式根参数优先于所有文件配置。
- 项目配置优先于用户配置，但项目层一旦存在读取、JSON 或已知字段错误，`maxDepth` 直接使用内置默认值 `2`，不回退到用户层。
- 用户层出现同类错误时也直接使用默认值 `2`。
- 未知字段产生 UI 警告后被忽略，不影响同层合法的 `maxDepth`。
- 文件配置问题通过 `ctx.ui.notify(..., "warning")` 类似的 UI-only 通道呈现；原型中的 `modelContextEntries` 始终为空。
- 显式根参数非法时根会话不启动，因此没有运行中 UI 或模型上下文。

## 有意不做的内容

- 不读取真实文件、不解析真实 JSON、不调用 Pi UI。
- 不实现 `maxChildrenPerAgent`、并发、成本、空闲回收或创建速率。
- 不提供生产级错误处理、持久化或测试套件。
